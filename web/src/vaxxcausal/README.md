# 一覧表切抜き画像の生成と検証

`build_vaxxcausal_crops.rb` は、厚生労働省資料の全ページPNGから一覧表の症例行を切り出し、次の3種類を同時に生成します。

- `raw/`: 赤枠と同じ座標から切り出した無加工画像
- 親ディレクトリの掲載画像: 文字を縮小せず、セル内の空白だけを横方向に除いた画像
- `audit/`: rawを上、掲載画像を下に並べた目視確認用画像

生成時には、文字判定に使う濃度以下の画素が削除区間に一つでもあれば処理を停止します。各セルの元範囲、残した範囲、削除した空白範囲、検査結果、rawと掲載画像のSHA-256は `compact-manifest.json` に記録します。

```sh
ruby build_vaxxcausal_crops.rb
```

処理後は `audit/*.png` を一枚ずつ原寸で開き、次を目視確認します。

1. 上段rawと下段掲載画像に同じ文字と罫線がある。
2. 文字の先頭・末尾・上下端が切れていない。
3. 別症例の行が混入していない。
4. 全ページ表示の赤枠が `compact-manifest.json` の `source_box` と一致する。
